## 1. Moyenne — `setTitleBarOverlay` n'existe pas sur macOS

**Journal (à chaque lancement) :**

```
Error occurred in handler for 'app:setWindowTheme': TypeError: window.setTitleBarOverlay is not a function
    at setWindowTheme (…/app.asar/dist/electron/main.js:1457:28)
```

**Cause.** `src/electron/main.ts:132` — `setWindowTheme()` appelle `window.setTitleBarOverlay(...)` sans test de plateforme. Cette API Electron n'existe que sous Windows et Linux. Le renderer (`src/renderer/App.tsx:79`) avale le rejet (`.catch(() => undefined)`), donc pas de plantage visible, mais une erreur à chaque lancement et changement de thème. `setBackgroundColor` passe avant l'erreur, donc le fond de fenêtre est correct.

**Correctif proposé (sans effet sur Windows) :**

```ts
if (!dock.docked && process.platform !== 'darwin') window.setTitleBarOverlay(titleBarOverlay());
```

(même garde que Nebula Clock, `apps/desktop/src/windows.ts:36`).

## 2. Moyenne — mise à jour automatique en erreur sur macOS

```
Error: Cannot find latest-mac.yml in the latest release artifacts
(https://github.com/Memel-SQT/Nebula-Finterest/releases/download/v0.1.38/latest-mac.yml): HttpError: 404
```

`autoUpdater.on('error')` (`src/electron/main.ts:312`) relaie l'erreur à l'UI (`state: 'error'`). Les releases GitHub ne contiennent que l'installeur Windows et `latest.yml`. Sur macOS, electron-updater exige en plus une app **signée et notarisée** (Squirrel.Mac). Sans signature, la mise à jour automatique ne peut pas fonctionner, même avec un `latest-mac.yml`.

**Pistes.** Désactiver la vérification sur un build Mac non signé (`process.platform === 'darwin' && !signé`), ou publier des builds Mac signés avec `latest-mac.yml` + `.zip`.

## 3. Faible — pas de `.zip` dans la cible Mac

`package.json` → `build.mac.target: ["dmg"]`. electron-updater sur macOS télécharge le `.zip`, pas le `.dmg`. Ajouter `zip` si la mise à jour Mac est un jour visée.

## Remarques

- `app.on('activate')` est bien géré (`main.ts:81`) : la fenêtre se rouvre depuis le Dock.
- Avertissement electron-builder sans conséquence : `duplicate dependency references react@18.3.1, loose-envify@1.4.0`.
